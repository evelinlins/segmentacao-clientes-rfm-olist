# Segmentação de Clientes RFM: E-commerce Olist 📊

# Objetivo de Negócio
O objetivo deste projeto é classificar a base de clientes da Olist para otimizar o investimento em marketing. Utilizei a metodologia **RFM (Recência, Frequência e Valor Monetário)** para identificar quem são os clientes mais valiosos e quem está em risco de evasão (churn).

# O que é o RFM aplicado:
* **Recência (R):** Dias desde a última compra.
* **Frequência (F):** Quantidade total de pedidos.
* **Monetário (M):** Valor total gasto na plataforma.

# Stack Técnica:
* **Python** com foco em manipulação pesada de dados (**Pandas/NumPy**).
* **Lógica de Dados:** Criação de scores de 1 a 5 para cada pilar do RFM.
* **PyCharm** como ambiente de desenvolvimento profissional.

# Resultados e Insights:
* **Segmentação Estratégica:** Clientes divididos em categorias como "Campeões", "Fiéis", "Em Risco" e "Perdidos".
* **Impacto:** Identificação de que uma pequena parcela da base (Campeões) é responsável por grande parte do faturamento, permitindo campanhas de fidelização personalizadas.
